# BTaskAssistant

BTaskAssistant 是一个面向 AI 辅助开发的任务工作流助手，用于把零散需求整理成可确认、可执行、可审核的开发任务。

## 核心流程

1. **任务收集**：手动添加任务，或从聊天记录、任务面板等来源导入。
2. **需求整理**：基于真实资料补全需求；遇到缺失或歧义时交由人工确认。
3. **提示词生成**：将确认后的需求整理成可直接交给 Codex、PI Agent 等工具执行的提示词。
4. **开发执行**：委托 AI 完成开发，并保留人工检查与干预入口。
5. **审核完成**：运行自测、代码审查和必要的小范围修复，确认后关闭任务。

## 项目状态

项目已初始化，具体功能与技术方案将随着需求确认逐步补充。
