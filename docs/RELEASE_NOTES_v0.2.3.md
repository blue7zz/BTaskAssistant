# BTaskAssistant v0.2.3

这一版完善了 Plane 收集箱的上下文读取与筛选体验。收集工作项时会同时读取
评论，并允许按负责人快速缩小候选范围。

## Plane 收集箱

- 新增负责人筛选，可选择全部负责人、具体成员或未分配工作项。
- 负责人使用 Plane 用户 ID 区分；升级前的旧候选仍可按名称兼容显示。
- 候选列表显示负责人和评论数量。
- 候选详情新增 Plane 评论区，显示评论作者、时间、编辑状态和正文。
- 评论采用与 Plane 相近的头像、时间线和卡片信息层级。
- 评论会合并到不可变的 Plane 原始来源中，PI 提炼和人工确认都能看到完整上下文。

## 同步与兼容

- 使用 Plane 官方 work item comments API，支持游标分页。
- 评论按时间正序展示，单次最多读取 5000 条。
- 以 6 个受控 worker 并发读取评论，避免对较大项目进行无上限请求。
- 单条工作项的评论读取失败不会丢失工作项；界面会明确显示同步失败并提示重新收集。
- 旧版持久化数据会自动补齐负责人详情和评论字段。

## 安全与人工确认

- 评论正文只按纯文本展示，不执行 Plane 返回的 HTML。
- PAT 仍只保存在系统凭据库，不进入 SQLite、日志、Git 或发布包。
- Plane 工作项与评论只形成候选。只有用户点击“人工确认并转为任务”才会创建正式任务。
